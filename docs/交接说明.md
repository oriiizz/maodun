# 交接说明

访客问答只有一条链路：页面文字或语音识别结果进入 `POST /api/ask`，`Runtime.ask` 使用本地知识库检索和规则检查，需要生成时调用 DeepSeek 官方接口。检查后的 `spoken_text` 同时用于页面显示和 `POST /api/speech/synthesize`。响应里的 `evidence`、`citations` 为空。命中和错误只写在 `answer_audit`。

`QA_PROVIDER` 即使改成旧的千帆名称，也不会再调用千帆。百度语音识别和阿里云语音合成的配置继续使用。

## 资料在哪里、怎么导入

四份原始文件按文件名识别，放在同一个目录：

- 文件名包含“基础知识”的 Word
- 文件名包含“统一章节总表”的 Excel
- 文件名包含“主题知识库”的 Excel
- 文件名包含“馆藏手稿与书信”的 Excel

```bash
.venv/bin/python -m app.cli import-corpus "/资料所在目录"
```

本次导入目录是桌面上的“茅盾”文件夹。结果写入 `data/maodun.db` 的 `corpus_nodes`、`museum_items`、`basics_units`、`corpus_meta`。同一条目 ID 只有一个节点。写有“不进入正式RAG”的条目不进入访客索引。重新导入会替换上一份语料并重新加载内存索引。

管理页的演示 Excel 写入另一套 `entries` 表，访客提问不读取它。

## 规则和模型在哪里改

- 人物口吻、政治话题、私生活和不确定表达：`data/persona/system_rules.txt`。每次生成都会重新读取，改完下一问生效。
- 页面上的“数字化模拟”声明：`data/persona/maodun.yaml` 的 `disclaimer`。它不参与生成。
- 两表校对和禁用：`app/knowledge/collate.py`、`app/knowledge/permissions.py`。
- 馆藏范围：`app/knowledge/museum.py`。
- 输出检查和固定收束：`app/knowledge/guard.py`。
- 模型：项目根目录 `.env` 的 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。当前模型名按官方文档为 `deepseek-flash`，地址是 `https://api.deepseek.com/chat/completions`，思考模式关闭。余额查询是 `GET https://api.deepseek.com/user/balance`。

密钥不要写进 `web/`。改 `.env` 或 Python 后要重启服务。

## 费用、启动和备份

生成费用记在 DeepSeek 账号。语音识别记在百度账号。语音合成记在阿里云百炼账号。

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000/`。备份至少保留 `data/maodun.db`、`.env` 和四份原始资料。
